# Data

No sequencing data, reference genomes, population-genetics cohorts or generated
analysis outputs are distributed with this code archive.

Before running a workflow, obtain the corresponding data through the paper's
approved repositories or controlled-access process and record:

- repository name and accession;
- reference genome assembly and annotation release;
- checksum for every downloaded input;
- access date and any usage restrictions;
- local path mapping used by the pipeline.

The root `.gitignore` excludes common large genomics formats. Small synthetic
test fixtures may be added under `tests/fixtures/` in a future release.
