# Figure code

Figure workflows retain the previously curated panel-oriented layout:

```text
figures/<figure>/<panel>/<numbered script>
```

Run numbered scripts in order only after reading the panel README and replacing
cluster-specific paths. A panel directory records code support for that panel;
it does not guarantee that final Illustrator assembly, typography or labels are
generated programmatically.

The supplied archive contained defensible code matches for only a subset of
manuscript panels. Missing panels were not filled with invented code. Shared
engines that support several panels remain under `figures/Shared_Workflows/` or
the corresponding figure-level `Shared_Workflows/` directory.

See [`../docs/FIGURE_CODE_NOTES.md`](../docs/FIGURE_CODE_NOTES.md) for mapping
semantics, [`../docs/FIGURE_COVERAGE.md`](../docs/FIGURE_COVERAGE.md) for the
34-figure coverage matrix and
[`../docs/CAPTION_RECONCILIATION.md`](../docs/CAPTION_RECONCILIATION.md) for
resolved numbering conflicts.
