# Figure 2j-2k - sheep Hi-C processing

This folder contains the Juicer analysis that produces the Hi-C contact maps
used by Figure 2j and Figure 2k.

## Panel relationship

- Figure 2j displays the chr6:65,000,000-75,000,000 Hi-C view together with
  chromatin states and epigenomic tracks.
- Figure 2k displays the chr6:84,445,000-84,505,000 TMPRSS11A locus, including
  a higher-resolution Hi-C contact map and enhancer-gene links.

The scripts generate and validate the `.hic` files and export the two regional
contact matrices. The final multi-track layout is assembled with the other
panel tracks and is not generated by these Juicer scripts alone.

## Execution order

1. `01_prepare_sheep_juicer_reference.sh`
2. `02_run_juicer_one_sample.sh`
3. `03_run_juicer_array.sbatch`
4. `04_submit_juicer_array.sh`
5. `05_collect_juicer_qc.sh`
6. `06_filter_and_plot_hic_qc.py`
7. Review `07_mega_group_samples.tsv`
8. `08_build_group_hic_maps.sh`
9. `09_dump_figure2_hic_regions.sh`
10. `10_validate_hic_outputs.sh`

## Environment

```bash
mamba env create -f environment.yml
conda activate sheep_epimap_hic
```

Copy this folder to `/vol2/zhangshiwen/juicer/figure_code`, make the shell
scripts executable, and set `RUN_ONE`/`SBATCH_SCRIPT` only if a different
location is used.

```bash
chmod +x ./*.sh
./01_prepare_sheep_juicer_reference.sh
./04_submit_juicer_array.sh
```

After all sample jobs finish:

```bash
./05_collect_juicer_qc.sh
python 06_filter_and_plot_hic_qc.py \
  --basic-qc /vol2/zhangshiwen/juicer/work/juicer_qc/juicer_basic_qc.tsv \
  --distance-decay /vol2/zhangshiwen/juicer/work/juicer_qc/juicer_distance_decay.tsv \
  --outdir /vol2/zhangshiwen/juicer/work/juicer_qc/hic_qc_filter_out

./08_build_group_hic_maps.sh
./09_dump_figure2_hic_regions.sh \
  /vol2/zhangshiwen/juicer/work/mega_merge/Common_tissues/Common_tissues.MAPQ30.hic
./10_validate_hic_outputs.sh
```

The group-building step uses `juicer_tools pre` directly on selected
`merged_nodups.txt` files, followed by `addNorm`. This avoids re-entering the
full FASTQ alignment stage when valid Juicer pair files already exist.

If chromosome names inside the `.hic` file are `6` rather than `chr6`, run the
regional export and validation with `CHR6=6` and `TEST_CHROMOSOME=6`.

The 3D-DNA genome-assembly workflow from the source notes is excluded because
it does not generate Figure 2j or Figure 2k.
