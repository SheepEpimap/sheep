# Source archive

`SheepEpimap.md` is the English-translated author notebook used to reconstruct
the organized pipeline files. Chinese headings, comments and user-facing
messages were translated; computational commands, variables, source order and
historical HPC paths were otherwise retained. The original Chinese working
source remains outside the public repository. This archive is retained for
provenance and should not be treated as the executable entry point.

Use `../SOURCE_CODE_MAP.tsv` to trace an organized script back to the source
line range.
